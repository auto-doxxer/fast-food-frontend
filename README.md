# Fast Food Queue System — Frontend

Tampilan web sistem antrean restoran menggunakan React + Vite.

> Backend: https://github.com/auto-doxxer/fast-food-queue — **jalankan backend dulu sebelum frontend!**

## Cara Menjalankan

### 1. Install Node.js
Download di https://nodejs.org → pilih versi LTS → install.

### 2. Install dependencies
```powershell
npm install
```

### 3. Jalankan
```powershell
npm run dev
```

Buka browser di **http://localhost:5173**

---

## Urutan Menjalankan

Buka 2 terminal secara bersamaan:

**Terminal 1 — Backend:**
```powershell
.\main.exe
```

**Terminal 2 — Frontend:**
```powershell
npm run dev
```

Lalu buka **http://localhost:5173** di browser.
